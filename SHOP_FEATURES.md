# Функционал интернет-магазина

## Клиентская часть (/)

### Главная страница магазина
- **URL**: `/`
- **Доступ**: Без авторизации
- **Функционал**:
  - Просмотр всех товаров
  - Фильтрация по магазинам
  - Фильтрация по категориям
  - Добавление товаров в корзину
  - Просмотр корзины
  - Оформление заказа

### Корзина
- Хранится в `localStorage`
- Показывает количество товаров
- **Изменение количества прямо из карточки товара** (кнопки +/-)
- Изменение количества в корзине
- Удаление товаров
- Подсчет общей суммы
- Оформление заказа

### Карточка товара
- **Клик на карточку** - открывает модальное окно с подробной информацией
- **Кнопка избранного** (сердечко) - добавить/удалить из избранного (только для авторизованных)
- Если товар **не в корзине** - показывается кнопка "В корзину" (открывает модалку для выбора размера)
- Если товар **в корзине** - показываются кнопки **− количество +**
- Можно увеличивать/уменьшать количество прямо из каталога
- При уменьшении до 0 товар удаляется из корзины
- Кнопка "+" неактивна, если достигнут максимум по размеру
- Избранные товары отмечены красным сердечком

### Страница товара
- Открывается при клике на карточку товара или кнопку "В корзину"
- URL: `/product?id={product_id}`
- Показывает:
  - Галерею изображений с переключением
  - Название, бренд, категорию, пол
  - Цену со скидкой (если есть)
  - **Описание товара** (если есть)
  - **Характеристики** (если есть)
  - Выбор размера (обязательно!)
  - Количество в наличии
  - Кнопку добавления в корзину
- После добавления в корзину - переход на главную с открытой корзиной

### Оформление заказа
- Запрашивает имя, телефон и email клиента
- Создает заказ в системе
- **Автоматически резервирует товары** (уменьшает количество на складе)
- Очищает корзину после успешного оформления

## Админ-панель (/admin)

### Доступ
- **URL**: `/admin`, `/admin/categories`, `/admin/products`, `/admin/orders`
- **Требуется**: Авторизация через `/auth`
- **Токен**: Сохраняется в `localStorage` и автоматически используется
- **Автоматический вход**: При переходе на `/auth` с валидным токеном - автоматическое перенаправление в админку
- **Проверка**: При переходе на любую страницу `/admin/*` проверяется токен в localStorage

### Функционал
- Управление категориями (CRUD)
- Управление товарами (CRUD)
  - Название
  - **Описание** (текстовое поле)
  - Количество
  - Цена
  - Изображение
  - Магазин
  - Категория
- **Загрузка изображений товаров**
- **Управление заказами**
- Просмотр статистики на дашборде

### Управление заказами (/admin/orders)
- Просмотр всех заказов
- Фильтрация по статусам (Все, Ожидают, Подтверждены, Отменены)
- Информация о клиенте (имя, телефон, email)
- Список товаров в заказе
- Общая сумма заказа

#### Статусы заказов:
- **pending** (Ожидает) - новый заказ, товары зарезервированы
- **confirmed** (Подтвержден) - заказ обработан и подтвержден
- **cancelled** (Отменен) - заказ отменен, товары возвращены на склад

#### Действия с заказами:
- **Подтвердить** - меняет статус на "confirmed"
- **Отменить** - меняет статус на "cancelled" и **возвращает товары на склад**
- **Удалить** - удаляет заказ и **возвращает товары на склад** (если статус pending)

## API Endpoints

### Публичные (без авторизации)
- `GET /api/stores` - список магазинов
- `GET /api/categories` - список категорий
- `GET /api/products` - список товаров
- `GET /api/products/{id}` - детали товара
- `POST /api/orders` - создание заказа (резервирует товары)

### Защищенные (требуют токен)
- `POST /api/stores` - создание магазина
- `POST /api/categories` - создание категории
- `POST /api/products` - создание товара
- `PUT/POST /api/categories/{id}` - обновление категории
- `PUT/POST /api/products/{id}` - обновление товара
- `DELETE /api/categories/{id}` - удаление категории
- `DELETE /api/products/{id}` - удаление товара
- `GET /api/orders` - список всех заказов
- `GET /api/orders/{id}` - детали заказа
- `POST /api/orders/{id}/status` - изменение статуса заказа
- `DELETE /api/orders/{id}` - удаление заказа
- `POST /api/images/upload` - загрузка изображения
- `POST /api/images/delete` - удаление изображения

## Логика резервации товаров

### При создании заказа (POST /api/orders):
1. Проверяется наличие товаров на складе
2. Если товаров достаточно - они **резервируются** (quantity уменьшается)
3. Создается заказ со статусом "pending"
4. Если товаров недостаточно - возвращается ошибка

### При отмене заказа:
- Товары **возвращаются на склад** (quantity увеличивается)
- Статус меняется на "cancelled"

### При удалении заказа:
- Если статус "pending" - товары **возвращаются на склад**
- Заказ удаляется из базы

### При подтверждении заказа:
- Статус меняется на "confirmed"
- Товары остаются зарезервированными (уже проданы)

## Загрузка изображений товаров

### Функционал:
- Загрузка изображений через админ-панель
- Поддерживаемые форматы: JPG, PNG, GIF, WEBP
- Максимальный размер: 5MB
- Изображения сохраняются в `storage/app/public/images/products`
- Доступны по URL `/storage/images/products/{filename}`

### В админ-панели:
- Превью загруженного изображения
- Кнопка удаления изображения
- Кнопка изменения изображения
- Отображение изображений в списке товаров

### В магазине:
- Изображения товаров в каталоге
- Изображения товаров в корзине
- Эффект увеличения при наведении (hover)

## Дизайн

### Цветовая схема
Все цвета настраиваются в `resources/js/config/theme.js`:
- **primary** (синий) - основной цвет для кнопок и акцентов
- **accent** (зеленый) - дополнительный цвет для цен и важных элементов
- **neutral** (серый) - нейтральные оттенки

### Карточки статистики на дашборде
Цвета карточек управляются через поле `color` в `dashboardCards`:
```javascript
{
    label: 'Название',
    value: 123,
    hint: 'Описание',
    color: 'primary', // primary, accent, success, gray, yellow, warning, error, info
}
```

Доступные цвета:
- `primary` - синий (основной)
- `accent` - зеленый (дополнительный)
- `success` - зеленый (успех)
- `gray` - серый (нейтральный)
- `yellow` - желтый (предупреждение)
- `warning` - желтый (предупреждение)
- `error` - красный (ошибка)
- `info` - синий (информация)

### Стиль
- Светлый минималистичный дизайн
- Градиентный фон (серый → голубой → зеленый)
- Чистые белые карточки
- Плавные переходы и hover-эффекты
