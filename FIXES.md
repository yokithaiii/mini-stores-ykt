# Исправления и улучшения

## 1. ✅ Исправлен баг с удалением товара из корзины

**Проблема:** При удалении товара через кнопки +/- на карточке удалялся неправильный товар.

**Решение:** 
- Функции `increaseQuantityFromCard` и `decreaseQuantityFromCard` теперь находят индекс товара и используют общие функции `increaseQuantity` и `decreaseQuantity`
- Все операции с корзиной теперь работают через индексы, а не ID

## 2. ✅ Исправлено отображение скидки в заказах

**Проблема:** В админке заказы показывали цену без скидки.

**Решение:**
- `OrderController` теперь сохраняет цену со скидкой (`discounted_price`)
- Добавлено поле `size` в таблицу `order_items`
- Резервация товаров теперь учитывает размеры
- Возврат товаров при отмене/удалении заказа учитывает размеры
- В админке отображается размер товара в заказе

**Изменения в БД:**
```sql
ALTER TABLE order_items ADD COLUMN size VARCHAR(255) NULL;
```

## 3. ✅ Размеры теперь обязательны

**Изменения:**

### Админ-панель:
- Размеры помечены как обязательные (красная звездочка)
- Валидация: минимум 1 размер обязателен
- Предупреждение если размеры не добавлены
- Для товаров без размера нужно указать "Универсальный" или "Без размера"
- Поле `quantity` товара теперь всегда 0 (используются только варианты)

### Клиентская часть:
- Убраны кнопки +/- из карточек товаров
- Теперь только кнопка "Подробнее" для открытия модалки
- В модалке размер ОБЯЗАТЕЛЕН для выбора
- Нельзя добавить в корзину без выбора размера
- Показывается количество каждого размера
- Индикатор "В корзине: X" под кнопкой

### API валидация:
```php
'variants' => 'required|array|min:1',
'variants.*.size' => 'required|string',
'variants.*.quantity' => 'required|integer|min:0',
```

## Складской учет

Теперь весь складской учет ведется ТОЛЬКО через размеры:

1. **Создание товара:** Обязательно добавить минимум 1 размер
2. **Добавление в корзину:** Обязательно выбрать размер
3. **Оформление заказа:** Резервируется конкретный размер
4. **Отмена заказа:** Возвращается конкретный размер на склад
5. **Удаление заказа:** Возвращается конкретный размер (если pending)
