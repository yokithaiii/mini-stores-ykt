# Аналитика продаж

## Что добавлено

### Backend
- **StatisticsController** - контроллер для получения статистики
- API endpoint: `GET /api/statistics?period={days}` (требует авторизации)

### Frontend
- **DashboardApp.vue** - компонент с графиками и метриками
- Интеграция с Chart.js для визуализации данных

## Метрики

### Карточки (сверху)
1. **Общая выручка** - сумма всех заказов за период (кроме отмененных)
2. **Количество заказов** - общее число заказов
3. **Средний чек** - средняя стоимость заказа
4. **Топ товар** - самый продаваемый товар с количеством продаж

### Графики

1. **Продажи по дням** (линейный график)
   - Показывает динамику выручки по дням
   - Помогает отслеживать тренды продаж

2. **Топ-5 товаров** (горизонтальный bar chart)
   - Самые продаваемые товары
   - Показывает количество проданных единиц

3. **Статусы заказов** (donut chart)
   - Распределение заказов по статусам
   - Pending / Confirmed / Cancelled

4. **Продажи по категориям** (pie chart)
   - Какие категории товаров популярнее
   - Помогает понять предпочтения покупателей

## Фильтры

Можно выбрать период:
- За 7 дней
- За 30 дней (по умолчанию)
- За 90 дней

## Технологии

- **Chart.js** - библиотека для графиков
- **Laravel** - backend API
- **Vue 3** - frontend компонент
- **Tailwind CSS** - стилизация

## Использование

1. Откройте админ-панель: `/admin`
2. Перейдите на вкладку "Дашборд"
3. Выберите нужный период в выпадающем списке
4. Анализируйте данные!
