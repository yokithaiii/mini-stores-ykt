# Расширенные возможности товаров

## 1. Размеры товаров (Варианты)

### Как это работает:
- Каждый товар может иметь несколько размеров (S, M, L или 40, 41, 42 и т.д.)
- У каждого размера свое количество на складе
- Общее количество = сумма всех размеров

### В админ-панели:
- Кнопка "+ Добавить размер"
- Поля: Размер (текст) и Количество (число)
- Можно добавить неограниченное количество размеров
- Если размеры не указаны, используется общее количество товара

### В магазине:
- В модальном окне товара отображаются все доступные размеры
- Покупатель выбирает размер перед добавлением в корзину
- В корзине показывается выбранный размер
- Один товар с разными размерами = разные позиции в корзине

## 2. Скидки

### Типы скидок:
1. **Без скидки** (none) - обычная цена
2. **Процент** (percent) - скидка в процентах (например, 20%)
3. **Фиксированная сумма** (fixed) - скидка в рублях (например, 500₽)

### В админ-панели:
- Выбор типа скидки из выпадающего списка
- Поле для ввода значения скидки
- Автоматическая валидация (процент не более 100%)

### В магазине:
- Зачеркнутая старая цена
- Новая цена со скидкой (зеленым)
- Бейдж со скидкой (красным)
- Автоматический расчет итоговой суммы в корзине

### Формулы:
```javascript
// Процент
discounted_price = price - (price * discount_value / 100)

// Фиксированная
discounted_price = max(0, price - discount_value)
```

## 3. Характеристики (Атрибуты)

### Как это работает:
- Произвольные пары "Ключ - Значение"
- Каждый товар может иметь свой набор характеристик
- Примеры:
  - Цвет: Красный
  - Материал: Хлопок
  - Подошва: Резина
  - Страна: Россия

### В админ-панели:
- Кнопка "+ Добавить характеристику"
- Два поля: Ключ и Значение
- Можно добавить неограниченное количество
- Пустые характеристики автоматически удаляются при сохранении

### В магазине:
- Отображаются в модальном окне товара
- Формат: "Ключ: Значение"
- Только если характеристики заданы

## API

### Структура данных товара:

```json
{
  "id": "uuid",
  "name": "Футболка",
  "description": "Описание товара",
  "price": 1000,
  "quantity": 0,
  "image": "/storage/images/products/image.jpg",
  
  "discount_type": "percent",
  "discount_value": 20,
  "discounted_price": 800,
  
  "attributes": [
    { "key": "Цвет", "value": "Красный" },
    { "key": "Материал", "value": "Хлопок" }
  ],
  
  "variants": [
    { "id": 1, "size": "S", "quantity": 3 },
    { "id": 2, "size": "M", "quantity": 5 },
    { "id": 3, "size": "L", "quantity": 2 }
  ],
  
  "total_quantity": 10
}
```

### Создание/обновление товара:

```javascript
POST /api/products
{
  "name": "Футболка",
  "price": 1000,
  "quantity": 0,
  
  "discount_type": "percent",
  "discount_value": 20,
  
  "attributes": [
    { "key": "Цвет", "value": "Красный" }
  ],
  
  "variants": [
    { "size": "S", "quantity": 3 },
    { "size": "M", "quantity": 5 }
  ]
}
```

## Корзина и заказы

### Корзина:
- Товары с разными размерами хранятся отдельно
- Цена рассчитывается с учетом скидки
- Ограничение количества по выбранному размеру

### Заказ:
```javascript
{
  "customer_name": "Иван",
  "customer_phone": "+7...",
  "items": [
    {
      "product_id": "uuid",
      "quantity": 2,
      "size": "M"  // опционально
    }
  ]
}
```

## База данных

### Таблица `products`:
- `discount_type` - тип скидки (none/percent/fixed)
- `discount_value` - значение скидки
- `attributes` - JSON с характеристиками

### Таблица `product_variants`:
- `product_id` - ID товара
- `size` - размер (строка)
- `quantity` - количество для этого размера
- Уникальность: (product_id, size)
