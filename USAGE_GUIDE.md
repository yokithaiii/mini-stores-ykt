# Руководство пользователя - Mini Stores

## Для покупателей

### 1. Просмотр товаров

**Каталог товаров:**
- Главная страница показывает все доступные товары
- Используйте фильтры для поиска нужного товара:
  - По категории
  - По бренду
  - По полу
  - По цене
- Сортируйте товары:
  - Сначала новые
  - Цена: дешевле
  - Цена: дороже

**Страница товара:**
- Клик на карточку или кнопку "В корзину" открывает страницу товара
- Уникальная ссылка для каждого товара (можно поделиться)
- Просмотр всех фотографий товара (галерея)
- Характеристики и описание
- Выбор размера (обязательно!)
- Кнопка "Назад в каталог"

---

### 2. Добавление в корзину

**Из каталога:**
1. Нажмите кнопку **"В корзину"** на карточке товара
2. Откроется страница товара с деталями
3. **Выберите размер** (обязательно!)
4. Нажмите **"Добавить в корзину"**
5. Вы вернетесь на главную с открытой корзиной

**Изменение количества:**
- Если товар уже в корзине, на карточке появятся кнопки **− количество +**
- Нажимайте **+** для увеличения количества
- Нажимайте **−** для уменьшения
- При уменьшении до 0 товар удаляется из корзины

**Ограничения:**
- Нельзя добавить больше, чем есть на складе
- Каждый размер считается отдельной позицией

---

### 3. Оформление заказа

1. Нажмите кнопку **"Корзина"** в шапке
2. Проверьте состав заказа
3. Измените количество при необходимости
4. Нажмите **"Оформить заказ"**
5. Заполните данные:
   - Имя
   - Телефон
   - Email
6. Подтвердите заказ

**После оформления:**
- Товары резервируются на складе
- Заказ получает статус "Ожидает"
- Если вы авторизованы - заказ появится в вашем профиле

---

### 4. Авторизация

**Зачем нужна авторизация:**
- Просмотр истории заказов
- Сохранение избранных товаров
- Быстрое оформление заказов

**Как войти:**
1. Нажмите кнопку **"Войти"** в шапке
2. Введите номер телефона
3. Нажмите **"Получить код"**
4. Введите код **1111** (в разработке)
5. Готово! Вы вошли в систему

**Выход:**
- Перейдите в профиль
- Нажмите кнопку **"Выйти"**

---

### 5. Личный кабинет

**Как попасть:**
- Нажмите на свое имя/телефон в шапке
- Или перейдите по адресу `/profile`

**Вкладка "Мои заказы":**
- История всех ваших заказов
- Статусы:
  - 🟡 **Ожидает** - заказ принят, ждет обработки
  - 🟢 **Подтвержден** - заказ обработан
  - 🔴 **Отменен** - заказ отменен
- Детали каждого заказа:
  - Список товаров
  - Размеры
  - Количество
  - Цены
  - Общая сумма

**Вкладка "Избранное":**
- Все товары, добавленные в избранное
- Быстрый переход к товару
- Удаление из избранного

**Редактирование профиля:**
- Измените имя
- Добавьте email
- Телефон изменить нельзя

---

### 6. Избранное

**Как добавить товар:**
1. Войдите в систему (обязательно!)
2. Нажмите на **сердечко** на карточке товара
3. Товар добавлен в избранное (сердечко станет красным)

**Как удалить:**
- Нажмите на красное сердечко еще раз
- Или удалите из вкладки "Избранное" в профиле

**Где посмотреть:**
- Нажмите на **сердечко** в шапке
- Или перейдите в профиль → вкладка "Избранное"

---

## Для администраторов

### 1. Вход в админку

1. Перейдите по адресу `/auth`
2. Войдите через email или телефон
3. После входа откроется админ-панель

---

### 2. Управление товарами

**Добавление товара:**
1. Перейдите в раздел **"Товары"**
2. Нажмите **"Новый товар"**
3. Заполните данные:
   - Название (обязательно)
   - Описание
   - Цена (обязательно)
   - Магазин (обязательно)
   - Категория (обязательно)
   - Бренд (опционально)
   - Пол (опционально)
4. Загрузите изображения:
   - Основное изображение
   - Дополнительные изображения
5. Добавьте **размеры** (обязательно!):
   - Размер (S, M, L или 40, 41, 42)
   - Количество для каждого размера
6. Добавьте скидку (опционально):
   - Процент (%)
   - Фиксированная сумма (₽)
7. Добавьте характеристики (опционально):
   - Цвет, материал, страна и т.д.
8. Нажмите **"Создать"**

**Важно:**
- Поле "Количество" убрано - используйте только размеры!
- Минимум один размер обязателен
- Для товаров без размера укажите "Универсальный"

**Редактирование:**
- Нажмите **"Изменить"** на карточке товара
- Измените нужные поля
- Нажмите **"Обновить"**

**Удаление:**
- Нажмите **"Удалить"** на карточке товара
- Подтвердите удаление

---

### 3. Управление заказами

**Просмотр заказов:**
1. Перейдите в раздел **"Заказы"**
2. Фильтруйте по статусам:
   - Все
   - Ожидают
   - Подтверждены
   - Отменены

**Информация о заказе:**
- Номер заказа
- Дата и время
- Данные клиента (имя, телефон, email)
- Список товаров с размерами
- Общая сумма

**Изменение статуса:**
- **Подтвердить** - заказ обработан
- **Отменить** - товары вернутся на склад

**Удаление заказа:**
- Нажмите **"Удалить"**
- Если статус "Ожидает" - товары вернутся на склад

---

### 4. Управление категориями

1. Перейдите в раздел **"Категории"**
2. Нажмите **"Новая категория"**
3. Введите название
4. Нажмите **"Создать"**

**Редактирование/Удаление:**
- Аналогично товарам

---

### 5. Управление брендами

1. Перейдите в раздел **"Бренды"**
2. Нажмите **"Новый бренд"**
3. Заполните:
   - Название (обязательно)
   - Описание (опционально)
4. Нажмите **"Создать"**

---

## Частые вопросы

### Для покупателей:

**Q: Не могу добавить товар в корзину**
A: Убедитесь, что выбрали размер в модальном окне товара

**Q: Не вижу свои заказы**
A: Войдите в систему через кнопку "Войти" в шапке

**Q: Забыл код для входа**
A: В разработке код всегда **1111**. В продакшене запросите новый код.

**Q: Не могу добавить в избранное**
A: Функция доступна только для авторизованных пользователей

**Q: Товар исчез из корзины**
A: Корзина хранится в браузере. Если очистили кэш - корзина сбросится.

### Для администраторов:

**Q: Не могу создать товар без количества**
A: Добавьте хотя бы один размер с количеством. Поле "Количество" больше не используется.

**Q: Товар показывает неправильное количество**
A: Проверьте количество в размерах. Общее количество = сумма всех размеров.

**Q: Как вернуть товары на склад?**
A: Отмените заказ или удалите его (если статус "Ожидает")

**Q: Клиент не видит свой заказ**
A: Убедитесь, что клиент был авторизован при оформлении заказа

## Технические детали

### Для разработчиков:

**Стек:**
- Laravel 11
- Vue 3
- Tailwind CSS
- Axios

**База данных:**
- MySQL/PostgreSQL
- Таблицы: products, orders, customers, favorites, и др.

**API:**
- RESTful API
- Авторизация через заголовок `X-Customer-Phone`
- Админ-авторизация через Laravel Sanctum

**Локальное хранилище:**
- `customer_phone` - телефон клиента
- `customer_data` - данные клиента
- `shop_cart` - корзина
