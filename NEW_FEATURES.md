# Новые возможности магазина

## ✅ 1. Множественные изображения товара

### Админ-панель:
- Основное изображение (как раньше)
- Дополнительные изображения (неограниченное количество)
- Кнопка "+ Добавить изображение"
- Превью всех изображений с кнопкой удаления

### Клиентская часть:
- **Слайдер изображений** в модальном окне товара
- Главное изображение (большое)
- **Thumbnails** (миниатюры) под главным изображением
- Клик по thumbnail переключает главное изображение
- Активный thumbnail подсвечивается синей рамкой

## ✅ 2. Пол товара

### Значения:
- Мужской (male)
- Женский (female)
- Унисекс (unisex)
- Не указан (null) - необязательное поле

### Где отображается:
- В модальном окне товара (рядом с брендом и категорией)
- В фильтрах магазина

## ✅ 3. Бренды

### Админ-панель (/admin/brands):
- Список всех брендов
- Создание нового бренда
- Редактирование бренда
- Удаление бренда
- Поля: Название, Описание

### В товарах:
- Выбор бренда из выпадающего списка
- Необязательное поле
- Отображается в модальном окне товара

### API:
- `GET /api/brands` - список брендов (публичный)
- `POST /api/brands` - создание (админ)
- `POST /api/brands/{id}` - обновление (админ)
- `DELETE /api/brands/{id}` - удаление (админ)

## ✅ 4. Фильтры в магазине

### Доступные фильтры:
1. **Категория** - выпадающий список
2. **Бренд** - выпадающий список
3. **Пол** - выпадающий список (мужской/женский/унисекс)
4. **Цена** - диапазон (от - до)

### Функционал:
- Фильтры применяются автоматически при изменении
- Показываются активные фильтры в виде бейджей
- Кнопка "Сбросить все" для очистки всех фильтров
- Клик по бейджу удаляет конкретный фильтр
- Фильтр по цене учитывает скидки

### Логика фильтрации:
```javascript
// Все фильтры работают одновременно (AND)
products
  .filter(category)
  .filter(brand)
  .filter(gender)
  .filter(price >= min && price <= max)
```

## Использование

### Добавление товара с полным набором данных:
1. Заполнить основную информацию (название, цена)
2. Загрузить основное изображение
3. Загрузить дополнительные изображения
4. Выбрать бренд (опционально)
5. Выбрать пол (опционально)
6. Добавить размеры (обязательно, минимум 1)
7. Добавить скидку (опционально)
8. Добавить характеристики (опционально)

### Покупка товара:
1. Просмотр каталога с фильтрами
2. Клик на товар → открывается модалка
3. Просмотр всех фото через слайдер
4. Выбор размера (обязательно)
5. Добавление в корзину
6. Оформление заказа
