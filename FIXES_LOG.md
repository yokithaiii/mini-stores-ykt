### Исправление #1: Данные товара не загружаются на странице товара

**Проблема:**
- Страница товара открывается, но данные не отображаются

**Решение:**

### Исправление #3: Цена со скидкой не отображалась в избранном

**Проблема:**
- API возвращал товары без вычисляемого поля `discounted_price`
- Модель Product имела accessor, но он не включался в JSON автоматически

**Решение:**
Добавлен `appends` в модель Product:

```php
protected $appends = [
    'discounted_price',
    'total_quantity',
];
```

**Файлы:**
- `app/Models/Product.php`

**Результат:**
- Теперь `discounted_price` и `total_quantity` автоматически включаются в JSON ответ
- Избранное корректно отображает цены со скидками

## 18 ноября 2025 (продолжение)

### Улучшение #1: Универсальная корзина на всех страницах

**Проблема:**
- Корзина работала только на главной странице
- При добавлении товара со страницы товара - редирект на главную
- Неудобная навигация

**Решение:**
Создан отдельный компонент `CartSidebar.vue`:

**Возможности:**
- Универсальный компонент корзины
- Работает на любой странице
- Автономное управление состоянием
- События `@close` и `@update` для синхронизации

**Интеграция:**
1. **Страница товара** (`ProductDetailApp.vue`):
   - Добавлен компонент `CartSidebar`
   - При добавлении товара - корзина открывается на месте
   - Нет редиректа на главную
   - Кнопка корзины в шапке с счетчиком

2. **Профиль клиента** (`CustomerProfileApp.vue`):
   - Добавлен компонент `CartSidebar`
   - Кнопка корзины в шапке
   - Счетчик товаров обновляется автоматически

3. **Главная страница** (`ShopApp.vue`):
   - Уже была корзина, работает как раньше

**Файлы:**
- `resources/js/components/CartSidebar.vue` (новый)
- `resources/js/components/ProductDetailApp.vue`
- `resources/js/components/CustomerProfileApp.vue`

**Функционал CartSidebar:**
```javascript
// Props
show: Boolean - показать/скрыть корзину

// Events
@close - закрытие корзины
@update - обновление счетчика товаров

// Функции
loadCart() - загрузка из localStorage
saveCart() - сохранение в localStorage
increaseQuantity() - увеличить количество
decreaseQuantity() - уменьшить количество
removeFromCart() - удалить товар
checkout() - оформление заказа
```
