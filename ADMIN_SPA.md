# Админ-панель SPA

## Что сделано

Админ-панель теперь работает как полноценное SPA приложение с Vue Router.

### Структура

```
resources/js/
├── admin.js              # Точка входа для админки
├── AdminApp.vue          # Главный компонент админки
├── router/
│   └── admin.js          # Роутер для админки
└── components/admin/
    ├── DashboardApp.vue  # Дашборд с аналитикой
    ├── CategoriesApp.vue # Управление категориями
    ├── ProductsApp.vue   # Управление товарами
    ├── BrandsApp.vue     # Управление брендами
    └── OrdersApp.vue     # Управление заказами
```

### Маршруты

- `/admin` - Дашборд с аналитикой
- `/admin/categories` - Категории
- `/admin/products` - Товары
- `/admin/brands` - Бренды
- `/admin/orders` - Заказы

### Особенности

1. **Единая навигация** - шапка с навигацией общая для всех страниц
2. **Без перезагрузки** - переходы между страницами мгновенные
3. **Защита роутов** - автоматическая проверка авторизации
4. **Отдельная сборка** - админка и магазин собираются отдельно

### Авторизация

- Токен хранится в `localStorage` под ключом `admin_token`
- При отсутствии токена редирект на `/auth`
- Кнопка "Выйти" очищает токен и перенаправляет на авторизацию

### Сборка

Теперь Vite собирает два приложения:
- `app.js` - магазин (клиентская часть)
- `admin.js` - админ-панель

Команда для сборки:
```bash
npm run build
```

### Преимущества

✅ Быстрая навигация без перезагрузки страницы
✅ Единый интерфейс и навигация
✅ Меньше дублирования кода
✅ Лучший UX для администраторов
✅ Легче добавлять новые страницы
